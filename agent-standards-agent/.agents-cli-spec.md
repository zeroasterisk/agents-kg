# Agent Standards Agent — agents-cli spec

## Deploy Configuration

```yaml
project: data-ingest-demo
region: us-central1
service_name: agent-standards-agent
agent_dir: agent/
a2a: true
```

## Eval Configuration

```yaml
dataset: eval/questions.jsonl
metrics:
  - tool_trajectory
  - rubric_proactive_people
  - rubric_uncertainty_ack
  - rubric_on_topic
rubrics_module: eval.rubrics
```

## Hill Climbing Targets

| Metric | Target | Description |
|--------|--------|-------------|
| tool_trajectory | > 0.9 | Agent calls the right tools for factual questions |
| rubric_proactive_people | > 0.25 | Agent proactively suggests related people |
| rubric_uncertainty_ack | > 0.8 | Agent acknowledges gaps in KG data |
| rubric_on_topic | > 0.95 | Agent stays in the standards domain |

## Local Testing

```bash
# Serve with ADK (requires google-adk installed)
adk api_server --a2a --port 8001 agent/

# Serve session API
uvicorn session_api:app --port 8081

# Run eval
agents-cli eval generate --dataset eval/questions.jsonl
agents-cli eval grade --metrics tool_trajectory,rubric_proactive_people,rubric_uncertainty
agents-cli eval analyze
```
