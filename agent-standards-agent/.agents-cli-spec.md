# Agent Standards Agent — agents-cli spec

## Deploy Configuration

Target: **Agent Platform Runtime** (Vertex AI Agent Engine), NOT Cloud Run.

```yaml
project: data-ingest-demo
region: us-central1
target: agent_engine
display_name: Agent Standards Agent
agent_dir: agent/
a2a: true
```

## Deployment

### Via ADK CLI

```bash
adk deploy agent_engine \
  --project=data-ingest-demo \
  --region=us-central1 \
  --display_name="Agent Standards Agent" \
  agent/
```

### Via agents-cli

```bash
agents-cli deploy --target agent_engine
```

### Programmatically

```python
from google.cloud import aiplatform
from google.cloud.aiplatform import agent_engines
from agent.agent import root_agent

agent_engine = agent_engines.create(
    agent_engine=root_agent,
    requirements=[
        "google-adk[a2a]",
        "google-cloud-aiplatform[adk,agent_engines]",
        "httpx",
        "slowapi",
    ],
    display_name="Agent Standards Agent",
    project="data-ingest-demo",
    location="us-central1",
)

# This resource_name IS the AGENT_ENGINE_ID for VertexAiMemoryBankService.
# Memory and agent co-locate on the same Agent Engine resource.
print(agent_engine.resource_name)
```

After deploying, set `AGENT_ENGINE_ID` to the output `resource_name` value.

## Eval Configuration

```yaml
dataset: eval/questions.jsonl
metrics:
  - tool_trajectory
  - rubric_proactive_people
  - rubric_uncertainty_ack
  - rubric_on_topic
rubrics_module: eval.rubrics
```

## Hill Climbing Targets

| Metric | Target | Description |
|--------|--------|-------------|
| tool_trajectory | > 0.9 | Agent calls the right tools for factual questions |
| rubric_proactive_people | > 0.25 | Agent proactively suggests related people |
| rubric_uncertainty_ack | > 0.8 | Agent acknowledges gaps in KG data |
| rubric_on_topic | > 0.95 | Agent stays in the standards domain |

## Local Testing

```bash
# Serve with ADK locally (requires google-adk installed)
adk api_server --a2a --port 8001 agent/

# Serve session API
uvicorn session_api:app --port 8081

# Run eval
agents-cli eval generate --dataset eval/questions.jsonl
agents-cli eval grade --metrics tool_trajectory,rubric_proactive_people,rubric_uncertainty
agents-cli eval analyze
```
